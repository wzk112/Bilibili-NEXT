# Mac 标题栏与搜索浮层

从完整定制版迁移到上游 1.1.7（1f8962b），保留新版 MacSidebar、个人中心、目录、直播与更新实现。

- 搜索栏与窗口红绿灯同排，顶部留 8 点，移除搜索栏下整条背景。
- 搜索历史/联想为覆盖层，不挤动内容；点击框外、按 Escape、提交搜索、窗口失焦后收起。
- 顶部空白区域支持拖动及双击缩放，按钮和搜索框保留自身交互；外侧边缘交给 AppKit 调整窗口大小。
- 红绿灯在同步布局回合调整位置，避免窗口缩放时先后两套位置抖动。
- 设置窗口隐藏标题，透明标题栏使用当前主题窗口背景。

本轮 `swift test`：290 项通过。真实 NSWindow 连续放大/缩小 24 次，每次同步及异步采样，三个按钮高度变化均低于 0.5 点；实际事件处理路径验证框内/浮层内点击保持、框外收起。首次完整回归只有既有 CoverPreview 80ms 延时测试因调度竞争失败，后续完整回归通过，未改动该测试或封面预览实现。

尚未对独立分支进行全部屏幕缩放、macOS 15 鼠标与主题外观组合验收。
