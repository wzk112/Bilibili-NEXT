# Mac 播放器可用空间布局

基于上游 1.1.7（1f8962b）独立迁移，不依赖标题栏或播放功能分支。

标题、视频和操作区组成首屏；按实际标题与操作区高度，为视频分配剩余空间，保持 16:9，不拉伸或裁切。移除 1280 点宽度上限与固定 250 点高度预留，简介从该首屏下方开始。紧凑控件依据实际视频宽度选择，避免宽窗口内因高度限制而变窄的视频仍塞入全部控件。主窗口最低高度为 720 点。

完整 `swift test`：289 项通过。实际 NSHostingView / NSWindow 排版测试覆盖 700×600、1400×900、2000×900 的播放器区域：比例正确、操作栏完整、视频达到宽或高约束。超宽且高度有限时仍会有比例造成的左右空白。

该分支不改直播/节目播放器，不代表所有设备、缩放和长错误提示组合已完成真实外观验收。
