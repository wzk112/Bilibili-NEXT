# Mac 四种主题（独立迁移）

基于 `5331d9a` 主干，保留原有外观为默认，新增白色、暗色和跟随系统主题；简洁主题使用中性背景与粉色强调色。原外观、玻璃与自定义背景配置保留，切回默认时恢复。系统外观单独观察，避免窗口显式颜色覆盖阻止跟随系统更新。

沿用上游 `AppGlass` 的 macOS 15 回退；主题分支没有替换目录、直播或更新实现。Mac 280 项 / 41 组测试通过；独立隐藏宿主窗口验证默认、白色、暗色、跟随系统的连续切换生效，且原颜色模式偏好保持不变。iOS 通用模拟器目标编译通过，`git diff --check` 通过。macOS 15 真机和本轮主题视觉仍需人工验收；构建主机的 CoreSimulator 服务版本不匹配，未据此声称执行了模拟器 UI 测试。
