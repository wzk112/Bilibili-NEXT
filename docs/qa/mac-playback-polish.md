# Mac 播放缓冲、定时暂停与操作反馈

基于上游 1.1.7（1f8962b）拆出；不包含窗口、导航、主题或网络策略改写。

- 使用 AVPlayer 可播放时间区间绘制缓冲进度，暂停时仍监听区间变化；保留空缺而非把下载字节当作可播进度。
- 15/30/60 分钟和本集结束定时暂停；倒计时跨集保留，手动换集取消本集结束模式，到期阻止自动下一集和起播恢复。
- 音量、静音、倍速快捷键提供短时反馈，操作后控制栏会再次自动隐藏。
- 本地 MP4 在真实 NSWindow / AVPlayer 宿主中验证解码出画、暂停、跳转、继续、定时到期和停止清理。

本轮完整 `swift test` 通过。macOS 15 启动已由用户验证完整定制包；此独立分支尚未在 macOS 15 真机逐项验收。
