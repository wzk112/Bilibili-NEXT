# 界面设计规则

使用 Apple 原生控件，按平台保留桌面和触控密度。共享尺寸由 `AppMetrics` 维护，Mac 的 `AppLayout` 引用同一套圆角和标题规则。

| 层级 | 规则 |
| --- | --- |
| 面板、分组、卡片外框 | 20 pt 圆角 |
| 视频与封面 | 12 pt 圆角；画面比例独立计算 |
| 内部项目与输入块 | 12 pt 圆角 |
| 紧凑控件 | 8 pt 圆角，保留系统菜单、开关和分段控件外观 |
| Mac 普通按钮与主搜索栏 | 32 pt 控件高度 |
| iPhone / iPad | 44 pt 触控范围；图标在范围内居中 |
| 模块内边距与分组间距 | 16 pt 为主；相邻小控件使用 8/12 pt；设置与宽屏容器保留更大的外边距 |
| 主模块标题 | Mac 26 pt 粗体；移动端使用可随系统文字大小缩放的 title2 |

左侧桌面导航组在账号区域上方的可用空间中垂直居中；短窗口减少留白并让导航内部滚动，账号与设置保留底部入口。

同排同级操作保持高度、基线和间距一致。圆形头像、胶囊、聊天气泡、系统导航栏与媒体边缘贴齐属于不同组件，不强行套成相同形状。

视频、评论和列表保留各自滚动与返回状态；缩窄后切换紧凑控件或上下布局，操作区可滚动到达。大字体时减少列数并使用上下布局。

验收包括浅深主题、触控范围、同排对齐、长标题、窄窗口、横竖屏、全屏返回和刷新。模拟器或当前 Mac 检查不能代替所有 macOS 15 设备及屏幕缩放组合。

参考：[Apple Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[UI Design Dos and Don’ts](https://developer.apple.com/design/tips/)。
