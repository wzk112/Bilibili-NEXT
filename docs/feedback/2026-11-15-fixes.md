# 2026-11-15 反馈修复候选

分支：`codex/feedback-fixes-2026-11-15`。基于 1.1.8 / iOS 0.1.7；尚未发布或覆盖正式安装，不改变版本号。来源见 [反馈复查](2026-11-15.md)。

## 已实施

| 项目 | 实现与范围 |
| --- | --- |
| 画质偏好 | 仅主动选择画质时保存偏好；打开视频、分 P、低画质回退和强制重试均不覆盖偏好。Mac / iOS 共用。既有被覆盖的偏好无法自动推断，主动选择一次所需画质即可重新保存。 |
| 手机搜索入口 | 首页目录菜单和搜索改用独立工具栏项目，保留原搜索页面和输入框。 |
| 移动端控制条 | 播放中闲置约 3 秒自动隐藏，点击唤回；暂停、加载/缓冲、拖动进度、弹幕设置和 VoiceOver 下保留。保留原生菜单挂载，避免计时隐藏时移除菜单锚点。关闭播放详情后重新显示。 |
| 自动画中画 | 「设置 → 播放 → 离开应用时自动画中画」，默认开启以保留旧行为；关闭后仍可手动启动 PiP，后台音频、应用内小窗各自独立。现有 PiP 控制器同步更新偏好。 |
| Mac 两类小窗 | 「设置 → 播放与网络」分别控制切换页面小窗和滚动播放页小窗，默认开启。关闭只隐藏小窗，音频继续，可返回正在播放页操作。 |
| Mac 非全屏放大 | 播放页增加「宽屏播放 / 适应窗口」。宽屏使用内容区全宽，操作区可向下滚动；默认仍采用原来适应窗口的布局。 |
| Duo 播放布局 | 手机导航保持原样；展开后有足够宽高时使用与 iPad 相同的播放布局，横向宽窗口左右分栏，窄窗口/竖向和辅助字号上下布局。展开窗口不自动强制横屏全屏。Duo 专项运行验收未完成，见下。 |
| 动态筛选 | 移动端新增「全部 / 视频」，请求对应服务端类型；筛选/账号变更清理旧数据和游标，迟到结果不覆盖新筛选。相同筛选刷新失败保留已有内容。 |
| 移动推荐反馈 | 推荐卡片长按增加「不感兴趣 / 不想看此 UP 主」；服务端确认成功后再移除当前列表对应项，失败显示错误，账号变化丢弃迟到结果。未发送真实推荐反馈。 |
| 弹幕排布保护与诊断 | 同一画布尺寸的连续 UIKit 布局不再反复取消尚未结束的排布任务；播放详情补充已加载、已排布、实际普通图层数量，并区分高级图层。QA 输出保存排布与可见数量。 |

弹幕修改解决一类排布任务被取消的问题；没有取得原评论的 BV 与设备，不能据此认定该用户的“开启但无弹幕”个案已完全修复。原有弹幕下载失败也不在本轮完成范围。

## Duo 模拟器事件与剩余边界

Duo 当前模拟器启动先报告 Data Migration Failed。尝试通过 `simctl io screenConfig` 切换其已有两块屏幕，横向 geometry 请求被运行时拒绝，未形成可用的展开横屏验收场景。随后用户贴出的崩溃报告显示，同一个模拟器的 SpringBoard 在 `SBMainDisplayConfigurationTransformer.transformDisplayConfiguration` 中断言退出；与本次屏幕配置测试的设备和时间吻合，很可能由该测试触发。该堆栈属于模拟器系统桌面，不能用来证明客户端自身崩溃。

已关闭此 Duo 模拟器以停止重复启动，保留全部设备数据，不执行抹除/重建；Duo 专项布局与跨折叠连续性**没有记为通过**。新增的展开手机布局测试保留供可用环境执行。iPad 相同布局的测试通过不替代 Duo 验收。

仍需真实环境：原弹幕失败样本、PiP 离开应用/锁屏实际行为、长时后台与音频中断、Duo 展开/折回、macOS 15 和原 HDR 样片。本轮没有执行真实评论、私信、推荐反馈或其他写入账号的操作。
